# Сценарий демо-видео — ИИ-агент поддержки (≤ 3 минуты, один дубль)

## Подготовка

| Что | Как |
|---|---|
| Стенд | `https://aisupport.dzenesis.ru`, прогон сквозного сценария перед записью |
| Браузер | один, чистый профиль: cookie от прошлых прогонов очистить |
| Код доступа | клиентский `ACCESS_CODE` — ввести один раз, cookie запомнит |
| Код менеджера | `MANAGER_ACCESS_CODE` — отдельный, для входа в кабинет |
| Звук | выключен: видео без монтажа, только экран |
| Разрешение | 1920×1080, масштаб браузера 100% |
| Таймер | секундомер рядом, чтобы не уехать за 3 минуты |

## Что жюри должно увидеть (по критериям Приложения 1)

| Критерий | Где в сценарии |
|---|---|
| Соответствие задаче | чат, подбор, КП, эскалация, журнал, база знаний |
| Корректность | суммы из каталога, ответы со ссылками, скидка уходит менеджеру |
| Потенциал внедрения | кабинет, настройки, песочница, аналитика |
| Готовность | всё работает на живом стенде, без заглушек |
| Агентность | уточняющие вопросы, последовательные шаги, эскалация |
| Экономика | стоимость диалога в трассе, аналитика по трассам |

## Чего НЕ делать

- Не показывать внутренние файлы, код, терминал.
- Не упоминать «прототип», «хакатон», «демо-версия».
- Не извиняться за что-либо: если что-то не сработало — показываем следующий шаг.
- Не открывать сторонние сайты (кроме стенда).
- Не задерживаться на одном экране дольше 15 секунд.

## Запасной план

Если на записи что-то падает:
1. не останавливать запись — продолжить со следующего шага;
2. после записи проверить, какой шаг упал;
3. перезаписать только если упало больше двух шагов подряд.

## Технические заметки для записи

- Вкладка MAX показывает живую ленту из базы — это настоящие сообщения, не макет.
- Кабинет менеджера требует отдельный код — ввести заранее, чтобы не тратить секунды.
- Знания: документ загружен заранее, одобрение делаем в кадре.
- Аналитика строится по фактическим трассам — цифры настоящие, не выдуманные.
