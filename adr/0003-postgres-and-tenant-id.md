# PostgreSQL 16 и tenant_id с первого дня

Используется одна база PostgreSQL 16 с pgvector для данных каталога, базы знаний, диалогов, документов, обещаний и трасс; `tenant_id` проставляется сервером из проверенной сессии в одной точке и ограничивает все запросы к данным арендатора. Полноценная мультитенантность с независимыми настройками, лимитами и биллингом не строится. До ответа владельца о доступной среде действует ASSUMPTION: локальный Node.js + Docker Compose с PostgreSQL 16/pgvector обеспечивает разработку и запись демо до появления выделенного стенда. Основание: `docs/HACKATON_BRIEF.md` §§9, 11; вопрос среды вынесен владельцу.
