# Документы и черновики статей одобряются раздельно до поиска

По решению владельца загруженные PDF/DOCX/MD/TXT и предложенные из диалогов черновики статей — отдельные сущности и операции/API. Документ проходит путь upload → parse → chunks → index → pending; статья — draft → review/approve → publish. Ни один источник не возвращается поиском до одобрения менеджером; неподдерживаемый формат отклоняется, а отсутствие одобренного источника ведёт к эскалации, а не к выдумыванию ответа. Один модуль чтения `knowledge` обслуживает оба опубликованных потока.
