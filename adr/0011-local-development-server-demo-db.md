# Локальная разработка и отдельная база на сервере

Разработка и миграции выполняются локально в Docker на PostgreSQL 16 с pgvector; параллельные агенты используют отдельные локальные базы. На сервере приложение развёртывается через Dokploy, а для стенда жюри используется отдельная база `support_agent`. Общая серверная база не используется для разработки: параллельные ветки и миграции не должны менять общие данные, а состояние сервера должно оставаться чистым и воспроизводимым для демонстрации жюри.
