# Node/TypeScript, DeepSeek через OpenCode Go и ограниченный retry

Для общего стека выбран Node.js/TypeScript с Next.js UI; DeepSeek через OpenCode Go — основной маршрут модели, custom endpoint — резервный. Один вызов LLM выполняет каждый шаг, та же модель обслуживает короткую классификацию. По `docs/HACKATON_BRIEF.md` §6 таймаут до первого токена LLM — 120 с, внутренний шаг — 5 с, общий бюджет диалога — 300 с; при 429 выполняется один повтор через 30 с; повторная ошибка или таймаут приводит к эскалации. Значение 10 с из макетов Ивы не является общим продуктовым SLA.
