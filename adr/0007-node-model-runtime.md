# Node/TypeScript and OpenCode Go for chat and embeddings

Проект использует Node.js/TypeScript с Next.js UI. Chat API вызывается через `https://opencode.ai/inference/go/v1/chat/completions` и требует заголовок `x-opencode-session: ses_<conversation_id>`; `deepseek-v4.1-flash` — основной маршрут после разрешения владельцем Global-региона, проверенный резерв — `gpt-5.6-luna`. Эмбеддинги БЗ/статей вызываются через `https://opencode.ai/inference/go/openai/v1/embeddings` с моделью `qwen3-embedding-8b` и размерностью 1536; session-заголовок не нужен. Не включённая в Go модель не подменяется молча: отказ доступности/региона приводит к эскалации.

Проверочные трассы: flash — 238 токенов, `list_cost` $0.00011445; `deepseek-v4-pro` — 1363 токена, $0.00254562; значения относятся к конкретным ответам и не являются фиксированной ценой каждого запроса. Подписка Go стоит $10/месяц с внутренним лимитом; embeddings стоят $0.01/1M входных токенов. Живые вызовы зависят от подписки/баланса владельца. По `docs/HACKATON_BRIEF.md` §6 тайм-аут до первого токена — 120 с, внутренний шаг — 5 с, весь диалог — 300 с; при 429 выполняется один повтор через 30 с, другие ошибки, повторная ошибка или таймаут ведут к эскалации. Значение 10 с из макетов Ивы не является общим продуктовым SLA.
