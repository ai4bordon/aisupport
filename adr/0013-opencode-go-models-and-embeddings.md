# Доступ к моделям и эмбеддингам OpenCode Go

По решению владельца вызовы модели используют маршрут OpenCode Go `https://opencode.ai/inference/go/v1/chat/completions`. Каждый вызов модели для Диалога передаёт заголовок `x-opencode-session: ses_<conversation_id>` для привязки вызова. Для демонстрации выбрана модель `deepseek-v4.1-flash` после разрешения владельцем Global-региона; проверенная резервная модель — `gpt-5.6-luna`. Проверенный резервный маршрут через custom endpoint в этом решении не выбран.

Живые вызовы DeepSeek Go и embeddings зависят от активной подписки и баланса владельца; для DeepSeek требуется разрешённый Global-регион. Проверенные `list_cost` относятся к конкретным ответам: flash — 238 токенов / $0.00011445; `deepseek-v4-pro` — 1363 токена / $0.00254562; фиксированной цены каждого вызова эти значения не задают. Отказы доступа/баланса (HTTP 402), региона (HTTP 400) и недоступного endpoint/model (HTTP 403) создают эскалацию с безопасной причиной. При HTTP 429 допускается один повтор через 30 секунд, после чего создаётся эскалация.

Эмбеддинги БЗ и статей вызываются через `https://opencode.ai/inference/go/openai/v1/embeddings` с моделью `qwen3-embedding-8b`, размерностью 1536 и без заголовка сессии. Тариф — $0.01 за 1M входных токенов в рамках Go; подписка Go стоит $10 в месяц с внутренним лимитом и учитывается отдельно. `text-embedding-3-small` в Go не входит и не используется. Основание: живые проверки, записанные supervisor в `.house/переписка.md` 27.11.2026.
