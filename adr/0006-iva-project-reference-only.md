# Система Ивы используется только как идея и UX-референс

Владелец запретил переносить в конкурсный продукт готовый код, разметку, CSS, токены и предспринтовые компоненты системы Ивы; реализацию прототипа создают участники во время спринта согласно Положению §§4.4, 4.8 и 9.1. Супервизор указал публичный репозиторий `https://github.com/smixs/iva-agent` с лицензией MIT; URL допустим как источник архитектурных/UX-идей, но лицензия не отменяет решения не заимствовать код. В одностраничной сдаче необходимо перечислить этот референс и отдельно раскрыть каждый реально использованный сторонний компонент с точной версией, лицензией и атрибуцией.
