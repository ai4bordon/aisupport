# Один процесс и семь узлов ядра

Для 48-часового спринта выбран один Node.js/TypeScript процесс с одним агентом и семью последовательными узлами обработки; модули `catalog`, `knowledge`, `documents`, `policy`, `promises` и `telemetry` вызываются через публичный `index.ts`, а наружу предоставляется один HTTP API. Web/MAX остаются адаптерами, ядро не зависит от канала. Это снижает операционные издержки и позволяет проверить один сквозной путь; отдельные сервисы и мультиагентность не входят в объём работ. Основание: решение владельца, `docs/HACKATON_BRIEF.md` §§4–6.
