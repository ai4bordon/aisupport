# ИИ-агент поддержки

Область продукта: поддержка покупателей B2B-магазина программного обеспечения через веб-чат и MAX с передачей сложных случаев менеджеру.

## Language

**Обращение**:
Сообщение или связанная последовательность сообщений клиента, на которые агент должен ответить либо которые он должен передать менеджеру.
_Avoid_: запрос, тикет клиента (если имеется в виду запись очереди менеджера)

**Диалог**:
Связанный обмен сообщениями одного клиента с агентом в одном канале; сохраняет контекст и историю обращения.
_Avoid_: сессия (если речь о продолжительной истории клиента)

**Эскалация**:
Передача обращения менеджеру, когда агент не имеет подтверждённых данных или полномочий для безопасного ответа.
_Avoid_: ошибка, передача (без указания ответственного человека)

**Коммерческое предложение (КП)**:
Документ с подобранным продуктом, ценой и условиями сделки, сформированный по запросу клиента на основании опубликованных данных каталога и утверждённых правил.
_Avoid_: оферта (если это не юридически утверждённая оферта)

**Счёт**:
Документ с суммой и реквизитами для оплаты заказа, сформированный из проверенных данных.
_Avoid_: КП, платёж

**Полномочия**:
Утверждённые правила, определяющие, какие коммерческие условия агент вправе предложить без согласования с менеджером.
_Avoid_: уверенность модели, policy (в пользовательских текстах)

**Обещание**:
Подтверждённое клиенту обязательство с установленным сроком и ответственным, зафиксированное для контроля исполнения.
_Avoid_: прогноз, предположение

## Знания и данные

**База знаний (БЗ)**:
Опубликованные и проверенные материалы, из которых агент может получать подтверждённые ответы.
_Avoid_: все загруженные файлы (неодобренные материалы ещё не входят в доступную для поиска БЗ)

**Документ БЗ**:
Загруженный менеджером PDF, DOCX, Markdown или TXT, который прошёл извлечение текста и индексацию и становится доступным поиску только после одобрения менеджером.
_Avoid_: черновик статьи

**Статья БЗ**:
Знание, предложенное из диалога как черновик и доступное для поиска только после одобрения менеджером.
_Avoid_: документ БЗ

**Чанк**:
Фрагмент текста документа, индексируемый и извлекаемый как часть источника БЗ.
_Avoid_: статья

**Источник ответа**:
Одобренный документ или статья БЗ, подтверждающий утверждение агента и доступный для цитирования.
_Avoid_: память модели

**Тенант**:
Магазин, чьи данные и обращения отделены от данных других магазинов логической меткой tenant_id.
_Avoid_: пользователь, диалог

## Работа агента

**Режим тени**:
Режим, в котором агент не отправляет ответ клиенту ни в веб-чат, ни в MAX, а сохраняет черновик ответа или эскалацию для менеджера.
_Avoid_: тестовый режим (если подразумевается только песочница)

**Трасса**:
Последовательная запись шагов агента, использованных инструментов и источников, результата, времени и данных о расходе модели.
_Avoid_: журнал обещаний (это отдельная запись бизнес-обязательства)
