# 03 — Загрузка, индексация и утверждение документов базы знаний

Status: open
Blocked by: 01
Type: task
Spec: `.specs/support-agent.md` requirement R6; ADR-0005
Plan: `docs/plans/03-document-upload-approval.md`

## Цель

Разделить загрузку документов и создание черновиков статей на основе диалогов. Загрузка менеджером поддерживает только PDF, DOCX, Markdown и TXT; индексированный источник становится доступным для поиска только после явного утверждения менеджером.

## Критерии приёмки

1. Загрузка принимает PDF/DOCX/MD/TXT, извлекает текст, создаёт чанки, индексирует и показывает статус «на проверке».
2. Любое другое расширение отклоняется с понятной ошибкой, и доступный для поиска источник не создаётся.
3. До утверждения менеджером поиск по базе знаний не возвращает чанки загруженного документа, а агент эскалирует/отвечает «нет в базе», вместо того чтобы сослаться на него.
4. После утверждения тот же запрос может получить чанки документа и ответ со ссылкой на этот источник.
5. Ошибки разбора/индексации оставляют документ недоступным для поиска и видимым менеджеру в восстановимом состоянии ошибки.
6. Фильтр опубликованных источников поиска применяется централизованно в модуле `knowledge`; прямые параметры запроса не позволяют раскрыть ожидающий контент.

## Команда проверки

`npm run test -- tests/integration/03-document-upload-approval.test.ts`

## Свидетельства демонстрации

Загрузите синтетический документ; задайте вопрос до утверждения и зафиксируйте отсутствие источника/эскалацию; утвердите документ; повторите запрос и зафиксируйте ответ со ссылкой. Не используйте реальные данные клиентов.
