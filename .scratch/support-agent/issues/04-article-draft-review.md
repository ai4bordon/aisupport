# 04 — Проверка и публикация черновиков статей, созданных по диалогам

Status: open
Blocked by: 01
Type: task
Spec: `.specs/support-agent.md` requirement R7; ADR-0005
Plan: `docs/plans/04-article-draft-review.md`

## Цель

Позволить менеджеру создавать/проверять черновик статьи из материалов диалога и публиковать его только после утверждения. Эта сущность и API остаются отдельными от загруженных документов.

## Критерии приёмки

1. Менеджер может создать черновик статьи со ссылкой на исходный диалог/материал и просмотреть его статус ожидания.
2. Содержимое ожидающего или отклонённого черновика исключается из поиска по базе знаний.
3. Утверждение/публикация переводит статью в доступное для поиска состояние, после чего поиск возвращает ссылку на её источник и содержимое.
4. Процесс статьи использует собственные операции `create`/`approve`/`publish`; он не переиспользует переходы состояний загрузки документов и случайно не публикует исходные файлы.
5. До утверждения агент не ссылается на черновик и не использует его для обучения.

## Свидетельства

Покажите результаты поиска до и после утверждения на синтетическом черновике статьи и зафиксируйте код выхода теста.
