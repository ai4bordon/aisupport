# 05 — Адаптер MAX Long Polling

Status: open

Type: task
Spec: `.specs/support-agent.md` requirements R9, R26; ADR-0002, ADR-0012

## Цель

Подключить опубликованный `@se15151074_bot` к общему ядру через проверенный путь MAX Bot API Long Polling для спринта/демонстрации. Владелец передаёт токен непосредственно исполнителю в начале реализации; его нельзя хранить в репозитории, чате, свидетельствах или описании продукта.

## Обязательный шаг плана

Перед реализацией ограничьте по времени разведку/проверку API с использованием реального бота и официальной документации. Эскалируйте владельцу, если не удаётся проверить доступ к API, веб-доступ к демонстрационному MAX или доставку входящих событий; не подменяйте канал поддельным.

## Критерии приёмки

1. Событие MAX `message_created` в реальном времени нормализуется в тот же нейтральный к каналу вход, который использует веб-чат, и достигает общего ядра.
2. Результат `respond` отправляет проверенный ответ через `POST /messages`; результат `escalate` создаёт элемент очереди менеджера и не отправляет неутверждённый ответ клиенту.
3. Для спринта/демонстрации используется режим опроса (polling); вебхук не требуется, если только владелец не подтвердит до соответствующего срока публичный HTTPS-хост с доверенным TLS.
4. Повторно воспроизведённые/дублирующиеся обновления не создают повторных ответов клиенту или повторных побочных эффектов эскалации.
5. Проверка в реальном времени использует `@se15151074_bot` и записывает вывод теста без токенов и заголовков авторизации.

6. Аватар реального MAX-бота использует предоставленный утверждённый логотип Softline без перерисовки или искажения и на контрастном фоне по R26; передаваемое изображение не содержит токенов или иных секретов.

## Свидетельства работы в реальном времени

Зафиксируйте реальное входящее сообщение, результат ядра и полученный ответ MAX или эскалацию. Не включайте учётные данные в свидетельства. Если доступ в реальном времени не работает, остановитесь и сообщите BLOCKED; не выдавайте поддельный/имитированный трафик за проверку в реальном времени.
