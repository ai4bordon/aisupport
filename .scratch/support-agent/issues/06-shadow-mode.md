# 06 — Режим тени в веб-чате и MAX

Status: open
Blocked by: 01, 05
Type: task
Spec: `.specs/support-agent.md` requirement R10; ADR-0008
Plan: `docs/plans/06-shadow-mode.md`

## Цель

Предоставить одну управляемую менеджером настройку режима тени, общую для веб-чата и MAX: сохранять результат в виде черновика/элемента очереди, подавляя все отправки клиентам.

## Критерии приёмки

1. При включённом режиме тени обычный результат ответа сохраняется как черновик в очереди менеджера, ответ в веб-чат не отправляется.
2. При включённом режиме тени `POST /messages` в MAX не вызывается; вместо этого записывается черновик/эскалация.
3. Отключение режима тени влияет только на новую обработку; подтверждённый источником и проверенный ответ можно отправить, но эскалация по-прежнему не приводит к отправке.
4. Записи очереди включают канал, диалог, причину/результат и безопасную ссылку на трассировку.
