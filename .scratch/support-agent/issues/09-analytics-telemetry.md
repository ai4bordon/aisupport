# 09 — Аналитика на основе трассировок и экономика диалогов

## Цель

Агрегировать проверенные записи событий/трассировок в операционную аналитику, не выдавая синтетические допущения за измеренные результаты.

## Критерии приёмки

1. Фактические трассировки раскрывают упорядоченные шаги, идентификаторы источников, результаты, модель/токены, измеренную длительность и настроенные цены; секретные данные и необработанные PII отсутствуют.
2. Аналитика подсчитывает завершённые диалоги, автоматические ответы, эскалации, длительности, пробелы в знаниях и затраты по сохранённым записям трассировок.
3. Индикаторы синтетических данных и демонстрационных трассировок видимы; оценочная экономия времени поддержки остаётся помеченной как оценка, если она не измерена по корректной базовой линии.
4. Агрегаты можно пересчитать по исходным трассировкам, и они не зависят от жёстко заданных демонстрационных процентов.

## Команда проверки

`npm run test -- tests/integration/09-analytics-telemetry.test.ts`

## Свидетельства

Используйте фиксированный набор записанных синтетических трассировок, независимо пересчитайте ожидаемые агрегаты и сравните с выводом аналитики.
