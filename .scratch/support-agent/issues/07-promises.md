# 07 — Учёт утверждённых обещаний клиентам

Status: open
Blocked by: 01, 02
Type: task
Spec: `.specs/support-agent.md` requirement R11
Plan: `docs/plans/07-promises.md`

## Цель

Хранить разрешённые обязательства перед клиентами и сроки их выполнения, чтобы менеджеры могли отслеживать статус и просроченные задачи без внешних интеграций уведомлений.

## Критерии приёмки

1. Обещание, полученное из разрешённого подтверждённого источником ответа, записывает диалог, текст обещания, срок выполнения, ответственного и статус.
2. Неизвестные/неутверждённые сроки не отправляются клиентам; вместо обещания, представленного как факт, создаётся эскалация.
3. Представление/API менеджера перечисляет открытые, выполненные и просроченные обещания с явной пометкой «синтетический/демонстрационный», где это применимо.
4. Внутренний учёт состояния сроков не подразумевает внешние интеграции напоминаний по email, CRM или MAX.

## Команда проверки

`npm run test -- tests/integration/07-promises.test.ts`

## Свидетельства

Покажите одно утверждённое обещание, один отклонённый/неподтверждённый срок и переход в состояние просрочки.
