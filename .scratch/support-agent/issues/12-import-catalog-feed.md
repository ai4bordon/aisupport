# 12 — Импорт товарного фида каталога и структурный поиск

Status: open
Blocked by: замороженный контракт (`docs/api-contract.md`, `docs/data-model.md`), не тикет 01
Type: task
Spec: `.specs/support-agent.md` requirements R1a, R1b, R19, R22; ADR-0010
Plan: `docs/plans/12-import-catalog-feed.md`

## Цель

Потоково импортировать предоставленный фид `Mindbox.yml.gz.xml` и обеспечить точный структурный поиск без векторного индекса каталога. Срез независим от ядра и использует только замороженные контракт и модель данных.

## Границы среза

- Владелец файлов: `src/import/catalog/**`, `src/modules/catalog/**`, `scripts/import-feed.ts`.
- Миграции: диапазон 1000–1999; номера закрепляет exec.
- Не меняет общие контракт, модель данных, роутер, корневую конфигурацию, ядро или чужие каталоги.
- Импорт и тяжёлая проверка на реальном файле выполняются не одновременно с обходом сайта БЗ.

## Критерии приёмки

1. Потоковый импорт реального файла создаёт 136 040 предложений и 9 311 категорий; полный путь категории вычисляется при импорте.
2. Значения параметров сохраняются как есть и доступны для точного фильтра по имени параметра; факт 387 имён параметров и 1 903 038 значений проверяется отчётом.
3. Позиция без `offer/@id` пропускается и отражается в отчёте; прерванный импорт продолжает работу по файлу состояния; повторный импорт идемпотентен по `offer/@id`.
4. Поиск поддерживает точный `offer/@id`, полнотекстовый поиск по названию, фильтры по вендору, категории с подкатегориями, `available` и параметрам. Неуникальный/пустой `vendorCode` не объединяет предложения.
5. Векторный индекс для каталога не создаётся; векторный поиск используется только для БЗ и статей.
6. Позиция с нулевой/неподтверждённой ценой возвращается с пометкой «цена не подтверждена заказчиком»; `available=true` означает наличие только в датированном снимке, а не текущий склад или срок.
7. По отсутствующему запросу возвращается пустой список, а не выдуманная позиция; каждая карточка сохраняет провенанс файла и снимка.

## Команда проверки

`npm run test -- tests/integration/12-import-catalog-feed.test.ts`

## Свидетельства

Отчёт импорта с числами источника; выборка пяти позиций, совпадающая с фидом; поиск и фильтры; повторный запуск; отсутствие каталожного вектора в схеме. Не запускать тяжёлый импорт одновременно с обходом сайта.
