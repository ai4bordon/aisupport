# 12 — Импорт товарного фида каталога и структурный поиск

Status: open
Blocked by: замороженный контракт (`docs/api-contract.md`, `docs/data-model.md`), не тикет 01
Type: task
Spec: `.specs/support-agent.md` requirements R1a, R1b, R19, R22; ADR-0010
Plan: `docs/plans/12-import-catalog-feed.md`

## Цель

Потоково импортировать предоставленный фид `Mindbox.yml.gz.xml` и обеспечить точный структурный поиск без векторного индекса каталога. Срез независим от ядра и использует только замороженные контракт и модель данных.

## Границы среза

- Владелец файлов: `src/import/catalog/**`, `src/modules/catalog/**`, `scripts/import-feed.ts`.
- Миграции: диапазон 1000–1999; номера закрепляет exec.
- Не меняет общие контракт, модель данных, роутер, корневую конфигурацию, ядро или чужие каталоги.
- Импорт и тяжёлая проверка на реальном файле выполняются не одновременно с обходом сайта БЗ.

## Критерии приёмки

1. Импорт прилагаемого снимка 25.11.2026 даёт временные базовые приёмочные числа до ответа Q&A: 136 040 предложений и 9 311 категорий; категории сохраняются с полным путём.
2. Живой URL `https://store.softline.ru/feeds/Softline.yml.gz` проверен 26.11.2026: 135 863 предложения, 513 категорий; все `parentId` разрешаются, дерево связно. Отдельный потоковый импорт этого источника ожидает 135 863 / 513 / 44 418 available / 55 587 positive-price, не приравнивая его к приложенному снимку. До ответа заказчика снимок — эталон данных, live URL — проверка потокового пути.
3. Снимок содержит 387 имён параметров, 1 903 038 значений параметров, 44 601 `available=true`, 55 771 положительную цену. Дата в поле без часового пояса временно трактуется как UTC; если заказчик подтвердит МСК, отображаемое время сдвигается на +3 часа.
4. Позиция без `offer/@id` пропускается и отражается в отчёте; прерванный импорт продолжает работу по файлу состояния; повторный импорт идемпотентен по `offer/@id`.
5. Поиск поддерживает точный `offer/@id`, русскую полнотекстовую конфигурацию `plainto_tsquery`, фильтры по вендору, категории с подкатегориями, `available` и параметрам. `pg_trgm` и `unaccent` отсутствуют: точный фразовый поиск не обещается. Неуникальный/пустой `vendorCode` не объединяет предложения.
6. Векторный индекс каталога не создаётся; векторный поиск используется только для БЗ и статей.
7. Позиция с нулевой/неподтверждённой ценой помечается; `available=true` относится к конкретному датированному источнику, а не гарантирует текущий склад или срок.
8. Пустой результат остаётся пустым; каждая карточка сохраняет provenance источника, дату фида и хеш снимка.

## Свидетельства

Отчёт импорта с числами источника; выборка пяти позиций, совпадающая с фидом; поиск и фильтры; повторный запуск; отсутствие каталожного вектора в схеме. Не запускать тяжёлый импорт одновременно с обходом сайта.
