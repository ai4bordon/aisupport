# 13 — Импорт базы знаний с сайта заказчика с провенансом

Status: open
Blocked by: замороженный контракт (`docs/api-contract.md`, `docs/data-model.md`), не тикет 01
Type: task
Spec: `.specs/support-agent.md` requirement R18; ADR-0005
Plan: `docs/plans/13-import-knowledge-site.md`

## Цель

Импортировать предоставленные заказчиком материалы `docs.softline.com` и `store.softline.ru/delivery_info/` как цитируемые источники базы знаний с провенансом и статусом `approved_by_customer`.

## Границы среза

- Владелец файлов: `src/import/knowledge/**`, `scripts/import-docs.ts`.
- Миграции: диапазон 2000–2999; номера закрепляет exec.
- Не меняет общие контракт, модель данных, роутер, корневую конфигурацию, ядро или чужие каталоги.
- Не смешивает импорт заказчика с загрузкой документов менеджером и черновиками статей; не запускается одновременно с тяжёлым импортом фида.

## Критерии приёмки

1. Обход идёт в ширину от восьми корней `id`, `lk`, `subscriptions`, `vendors`, `checkout`, `merchant-portal`, `payment`, `allsoft`, до глубины 3, дедуплицирует URL, соблюдает интервал не менее 1 секунды и отправляет понятный `User-Agent`.
2. Из каждой страницы сохраняются заголовок, путь разделов, основной текст, URL источника и дата обхода; в базу попадает извлечённый текст, сырой HTML сохраняется в кэше.
3. При 429 или 5xx обход останавливается с причиной, а уже собранные страницы сохраняются; следующий запуск использует кэш и не обращается к сайту повторно для закэшированных страниц.
4. Чанки имеют размер 800–1200 знаков и сохраняют заголовок, путь разделов и URL источника для цитирования.
5. Источник при импорте получает `status=approved_by_customer`, непустой провенанс `docs.softline.com, обход 26.11.2026` или `store_page`, и не проходит ручное одобрение; файл менеджера и черновик статьи по-прежнему требуют одобрения.
6. Поиск возвращает импортированный чанк с URL источника; запись трассы сохраняет идентификатор источника и дату обхода.
7. Детерминированный тест проверяет остановку на 429/5xx, сохранение собранного и повторное использование кэша; обход не создаёт параллельных запросов.

## Команда проверки

`npm run test -- tests/integration/13-import-knowledge-site.test.ts`

## Свидетельства

Отчёт обхода с просмотренными/импортированными страницами; источник с заголовком, путём, URL и провенансом; чанк с URL; остановка на 429 с сохранением собранного. Не запускать тяжёлый обход одновременно с импортом фида.
