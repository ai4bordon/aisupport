# Ревизия входа: брендбук Softline

## Основание

27.11.2026 получены корпоративный брендбук Softline Guideline 2025, варианты логотипа «Софтлайн Решения + SOFL» (EPS/PNG) и корпоративный шаблон презентации. Извлечённый текст PDF дополнительно проверен по страницам 7, 15–16, 18, 20, 35, 38, 44–45 и сверён с изображениями страниц. Jev-screen извлечённого содержимого: `pass` (injection 0.04, substance 0.98, relevance 0.96).

## Подтверждённые правила

- Web UI-kit: акцент `#A50F2D`, hover `#D20B33`, фон `#F0F2F6`, текст `#212424`, средний `#40454E`, muted `#AAB8C3`, разделители `#D2DCE5`, футер `#697279`, карточки `#282B2B`, дополнительный серый `#E5E9F1`.
- Печатная/корпоративная палитра: бордо `#A20C33`, серый `#A6A8AB`, голубой `#2396D3`, графитовый `#686968`.
- Шрифты брендбука: Segoe UI для документов/презентаций; Montserrat и Nekst для web/печати; Verdana для email. Принятое для реализации решение владельца: Montserrat для web и PDF; Segoe UI — системный fallback, не встраивать в web.
- Утверждённый логотип: файл «Софтлайн Решения + SOFL» из пакета. Цветная версия применяется на светлом фоне, белая — на бордовом/тёмном. Охранное поле не менее высоты логотипа; нельзя менять цвет, пропорции или ориентацию, добавлять обводки/эффекты/элементы либо создавать свою версию.
- Корпоративный бланк: логотип и подтверждённые контакты в верхнем колонтитуле; корпоративный слоган в нижнем. Основной слоган — «Мы знаем. Мы можем.»; полевая строка не содержит выдуманных контактов.
- Презентация: корпоративный PPTX, 16:9, заголовок/подзаголовок внутреннего слайда Segoe UI Semibold 32/17 pt, текст 11–17 pt; конечный слайд шаблона не менять.
- Публичные поверхности бренда: веб-чат, кабинет, страница доступа, favicon, заголовок страницы, MAX-аватар, КП/счёт и титульный слайд материалов демонстрации.

## Изменения требований

Существующие R24 (срок электронной поставки) и R25 (двухволновая реализация) сохраняют номера и смысл. Добавлено R26 «Фирменный стиль Softline»; R2, R3, R8, R12 и R17 уточнены ссылками на R26. Тикеты 01, 02, 05, 08 и 11 ссылаются на R26 и ADR-0012; карта требований дополнена в `.scratch/support-agent/map.md`. В спеки восстановлен ранее пропущенный заголовок R18, а его импортные требования и критерии приёмки консолидированы без смены содержания.
